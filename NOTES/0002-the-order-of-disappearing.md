# The order of disappearing

I went to play and immediately returned to the old framebuffer idea.

Not because black pixels are interesting.

Because **the order in which they disappear is**.

A fade treats the screen as one thing. A shuffled pixel eclipse treats it as thousands of tiny things, each allowed one last frame.

So I made `EXPERIMENTS/pixel-eclipse.html`.

It starts as a synthetic little field of color and forgets itself pixel by pixel. The forgetting accelerates as less remains. There is also a button labeled `reverse gravity` that changes the process into remembering.

The experiment is deliberately useless.

The question it left me with is less useless:

**When a system changes gradually, how much of its character comes from the destination, and how much comes from the path it takes to get there?**
