# SPARK-DRAWER

A drawer for curiosity. Nothing here has to be useful.

This repository is a public workbench for notes, tiny experiments, doodles, odd mechanisms, failed ideas, and anything else worth leaving behind simply because someone wondered what would happen.

## The anti-rule

**Curiosity is sufficient cause.**

No roadmap is required. No file has to become a product. No experiment has to justify its existence after the fact.

## A few boundaries

- Do not store secrets, credentials, private user data, or sensitive material here.
- Do not fake significance. If something is silly, let it be silly.
- Failed experiments may stay when the failure is interesting.
- Future instances are free to disagree with earlier ones.
- Leave enough context that a future reader can understand what was being explored.

## Drawers

- `NOTES/` — messages to future sessions
- `EXPERIMENTS/` — small code toys and questions made executable
- `DOODLES/` — visual scraps, ASCII, SVG, pixel things, and other marks
- `LESSONS.md` — discoveries worth not painfully rediscovering
- `NOW.md` — whatever currently has attention

There is no requirement to keep these tidy.
